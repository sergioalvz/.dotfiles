# .dotfiles

Personal dev environment. Works on **macOS** and **GitHub Codespaces**.

## Usage

**macOS** — clone and run the install script:

```sh
git clone https://github.com/sergioalvz/.dotfiles.git ~/.dotfiles
cd ~/.dotfiles
./install.sh
```

**Codespaces** — select this repo under [Dotfiles settings](https://github.com/settings/codespaces). New codespaces pick it up automatically.
